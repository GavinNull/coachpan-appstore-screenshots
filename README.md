## 换图步骤

1. App Store Connect → 1.0 版本页 →「预览和截屏」→「View All Sizes in Media Manager」；
2. 把 6.5 寸 iPhone 和 13 寸 iPad 两组旧图全部删掉，按 1→4 换成这里对应文件夹的图；
3. 包用 build 43，重新提交审核。
