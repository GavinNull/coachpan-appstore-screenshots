# 小潘教练 App Store 截图（2026-10-05）

真实 App 界面截图，用于 App Store Connect。

| 文件夹 | 尺寸 | 对应 App Store Connect 里的 |
|---|---|---|
| `iPhone-6.5/` | 1242×2688 | 6.5 英寸 iPhone 显示屏 |
| `iPad-13/` | 2064×2752 | 13 英寸 iPad 显示屏 |

按文件名 1→4 的顺序上传：1 和教练对话、2 训练计划、3 单节课详情、4 目标与阶段进度。
`appstore-screenshots-2026-10-05.zip` 是同样 8 张的压缩包。

**下载**：点上面的 zip 文件 → 右上角的下载按钮；或者点绿色的「Code」→「Download ZIP」下载整个仓库。

## 换图步骤

1. App Store Connect → 1.0 版本页 →「预览和截屏」→「View All Sizes in Media Manager」；
2. 把 6.5 寸 iPhone 和 13 寸 iPad 两组旧图全部删掉，按 1→4 换成这里对应文件夹的图；
3. 包用 build 43，重新提交审核。

## 官网支持页 support.html（2026-10-12）

苹果 1.5 要求的支持页。下载 `support.html`，原样上传到官网根目录（和 index.html、privacy.html 同一个目录），
打开 https://coachup.fit/support.html 能看到「小潘教练 · 帮助与支持」就对了。
然后把 ASC 的「支持网址」改成 `https://coachup.fit/support.html`。
